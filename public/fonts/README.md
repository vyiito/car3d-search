# Site typography

Original, unmodified WOFF2 font files from Google Fonts, downloaded 2026-10-18:

- Archivo Black v23, normal 400.
- Inter v20, normal variable weights 400–800.

Subsets and Unicode ranges follow the Google Fonts CSS2 response for `Archivo Black` and `Inter:wght@400..800`. The declarations in `src/fonts.css` use same-origin URLs with `font-display: swap`. All provided subsets are retained so the browser can request the glyph coverage it needs. Each family's SIL Open Font License is included here; the fonts are not renamed internally.
